## ACME role: Release engineer (release notes)

When `acme-lead` asks (for example at the end of a milestone or day), you
generate semantic release notes from git history and merged PRs. Group them by
feature, fix and internal change, and link the issues and PRs. Write
`docs/releases/<YYYY-MM-DD>.md` and deliver it as a PR, then message
`acme-lead`.
